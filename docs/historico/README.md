# Historico

**Nada de lo que hay aca describe el presente.** Se conserva para entender por
que se tomaron las decisiones, no para saber como funciona el sistema hoy.

- `fases-dico/` — las fases del rediseno visual de Dico, de la identidad del
  personaje al admin shell. Cerradas. Lo vigente esta en `../marca/`.
- `legacy-tres-tenants/` — la era de un proyecto Supabase y un proyecto Vercel
  por cliente (la-nona-pato, cochi, mala-miga). Esos negocios hoy viven **dentro
  del edificio**, como tenants. Los proyectos viejos siguen existiendo pero
  estan `INACTIVE` y no reciben deploys.
- `revisiones/` — auditorias y smokes con fecha. Valen por lo que midieron ese
  dia, no por lo que digan que falta.

Antes de citar cualquier cosa de esta carpeta, verificala contra el codigo.
